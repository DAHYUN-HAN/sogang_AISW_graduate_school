# 관리자 메인 웹 구현 검증 — 2026-10-07

작업: WP8 관리자 P0 / 기본 통계 P1, WP9 통합. 사용자 승인 시안에 이어 “메인부터 작업 시작” 요청을 적용했다. 변경은 `codex/web-admin-main` 작업 브랜치에 있으며 배포하지 않았다.

## 구현 범위

- 기존 Expo `/admin` 경로의 웹 기본 화면을 메인으로 변경했다. 흰 표면, Pretendard, 기존 색상과 얇은 구분선을 사용하며 관리자 경로만 회원용 405px 프레임에서 벗어난다. 기존 관리 메뉴/편집 기능과 네이티브 화면은 보존했다.
- 오늘 방문 수·방문자 수·페이지 조회, 어제/오늘 게시글·댓글 7개를 실제 서버 집계에 연결했다. 게시글은 공개 완료·비삭제 상태, 댓글은 남아 있는 답글까지 포함한다. 한국 시간 오늘/어제 경계를 사용한다.
- 상조회/건의사항 미처리는 접수일과 무관하게 유지한다. 완료·반려·답변 완료는 당일 처리 시각 기준으로만 표시한다. SQL 조건을 페이지네이션 전에 적용하며 총계와 이전/다음 이동을 제공한다. 캐시가 남아도 KST 자정 이후 전날 처리분은 제거하고 전날 숫자를 오늘 숫자로 표시하지 않는다.
- 상세 패널에서 신청 내용·권한이 확인된 증빙과 답변/처리 상태를 확인한다. 공식 답변·반려 사유를 검증하고 실패한 입력을 유지한다. 성공 후 메인/기록을 갱신한다. 닫기·Escape·이동 시 미저장 확인과 브라우저 새로고침/닫기 경고를 제공한다. 상세는 최신 응답을 받은 뒤 초안을 초기화한다.
- 최근 운영 기록 5건과 전체 기록의 페이지 이동을 연결했다. 기존 운영 로그에 관리자 게시글·공지·댓글 작성/수정/삭제를 보완했다. 로그와 변경은 같은 트랜잭션으로 저장하며 본문·계좌·증빙은 기록하지 않는다. 동일 처리 저장은 처리 시각과 로그를 변경하지 않는다.
- 요청한 안내 문장, 하단 빠른 작업, 이용 현황 보기 버튼을 제거했다.

## 트래픽과 실행

트래픽은 회원 전용 정책에 맞춰 **로그인한 일반 회원의 앱/웹 이용**을 집계한다. 관리자·비회원 이용, 같은 화면 재렌더, 일반적인 탭 재활성화는 제외한다. 30분 이상 비활동 후 이용은 새 세션으로 계산하며 동일 이벤트 재전송은 중복 저장하지 않는다. 앱은 수집 오류 때문에 이동을 차단하지 않는다. 새 프런트엔드를 사용한 시점부터 수집되므로 이전 설치 버전의 과거 이용을 복원하지 않는다. 수집 이전/비활성 지표는 가짜 0으로 표시하지 않는다.

백엔드 실행 전 `backend`에서 `alembic upgrade head`를 실행하여 `0032_admin_usage`를 적용해야 한다. `USAGE_TRACKING_ENABLED=true`가 기본이며 false로 쓰기를 중지할 수 있다. 비활성 상태에서도 개요가 테이블을 조회하므로 마이그레이션은 필요하다. 원본 URL·쿼리·IP·User-Agent·콘텐츠는 사용량 테이블에 저장하지 않는다. 보관 주기나 외부 분석 제공자는 추가하지 않았다.

메인의 숫자 클릭은 현재 기존 대시보드를 연다. 새 7일 추이·지표/날짜별 상세, 나머지 관리 화면의 전면 개편은 다음 작업이다. 이번 메인 구현을 전체 관리자 개편 완료로 취급하지 않는다.
