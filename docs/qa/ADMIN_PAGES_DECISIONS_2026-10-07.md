## 기능 보존 확인

게시판 단순화의 사용자 보정을 실제 화면에 반영했다. 큰 분류는 앱과 같은 원우회·참여활동·커뮤니티·공지사항 4개다. 공지사항은 `NOTICE_FILTERS`의 학사공지/행사공지/기타공지, 커뮤니티는 행사 사진첩/자료공유와 `RESOURCE_FILTERS`의 강의후기/시험족보/종합시험/졸업논문, 참여활동은 동아리/스터디/네트워킹과 안내(스터디는 모집)/활동 인증, 원우회는 현재 `MENU_ITEMS`의 7개 항목을 사용한다. 예전 DB 이름인 웨비나/특강 공지와 학사일정을 공지사항의 독립 태그로 나열하지 않는다. 실제 게시판/하위 게시판은 접힌 설정에서, 이전 항목은 추가 관리 항목에서 계속 관리한다. 새 게시판의 위치/부모 선택과 복원 가능한 하위 게시판 전체 숨김을 구현했다. 기존 데이터·게시판 ID·전용 관리 기능은 유지한다. 실제 구현/기본값/842개 프론트엔드 및 551개 백엔드 테스트·브라우저 검증은 `docs/qa/ADMIN_BOARDS_WEB_2026-10-07.md`에 기록했다.

배너 후속 변경: 웹의 노출 시작/종료 날짜는 달력, 시간은 시간 선택 도구를 사용한다. 시작 날짜를 처음 고르면 00:00, 종료는 23:59를 기본값으로 사용하고 분 단위 수정이 가능하다. 각 날짜를 해제하면 해당 노출 제한이 없어진다. 기존 UTC 저장값을 한국 시간으로 표시하고 저장 시 UTC로 변환한다. 잘못된 날짜와 종료 ≤ 시작은 API 호출 전에 차단한다. 게시글 연결은 게시 상태(published)의 글을 게시판 전체에서 검색하며 10건씩 페이지를 넘긴다. 직접 링크/연결 해제와 기존 업로드·이미지 URL·숨김·정렬 기능은 그대로 사용할 수 있다.

- 배너 신규/수정/숨김, 순서·활성·기간·링크/공지 연결, 모바일/태블릿/데스크톱 이미지, 업로드·미리보기·실패 안내.
- 게시판 13종 등록, 기존 타입/슬러그/그룹 잠금, 이름·설명·순서·권한·익명·활성 설정. 활동인증 이미지 규칙과 강의후기/시험족보/건의사항/동아리·네트워킹 고정 정책.
- 일반 글·자료·앨범·활동인증의 검색/필터/페이지, 상세/수정/고정/삭제, 동아리·네트워킹 신규 글/대표 이미지 교체, 활동인증 계좌 조건.
- 공지 분류·기간·본문·다중 이미지/진행·실패 안내/교체/제거·고정·원우회 활동 연동, 저장 후 고정 실패의 부분 저장 안내.
- 현재 원우회·기장단·역대 원우회별 소개, 갤러리·임원 이미지, 카드/임원 추가·삭제·순서, 역대 활동내역 줄 입력과 메타데이터 호환.
- 익명 건의사항 필터/공식 답변, 상조회 비공개 증빙과 완료/반려·사유, FAQ 등록/수정/취소/숨김, 일정 3종 분류·한국 날짜/시간 선택·수정/삭제.
- 외부 링크 검증/저장과 실패 시 초안 보존. 안내 게시판의 기존 안내/운영 설정을 유지하며 새로운 콘텐츠 저장 기능을 임의로 만들지 않음.
- 계정 검색·동의 기록·역할·활성·재학 상태, 명부의 누락 원우 보존/동일 학번 갱신, 회비 엑셀 전체 교체 확인과 개별 납부 설정.
- 신고 게시글/댓글 삭제 및 삭제 성공 후 신고 저장 실패의 부분 처리 안내, 정책 버전·전공 관리, 운영 기록과 이관 원장.
- 대시보드의 기존 운영 바로가기, D-day 수동 알림, 푸시 영수증 확인, 누적 통계, 최근 기록/게시글과 고정·수정·삭제.

기존 관리자 본문의 선언/처리기를 추출 전 코드와 독립 리뷰로 비교하여 제거된 기능이 없음을 확인했다. 웹에서 보이지 않던 React Native Alert의 삭제·숨김·권한 변경 확인/결과를 관리자 전용 확인창으로 연결했다. 회원 화면은 기존 동작을 사용한다.

## 주소·권한·통계

- 관리자 하위 주소 전체는 루트 관리자 보호 아래 있다. 서버의 명시적 관리자 의존성은 그대로 사용한다.
- 기존 `/admin?section=...`, scope, 일정 `editEventId` 링크와 네이티브 관리자 진입을 유지한다. 자동 링크 해석은 일정 query를 지우지 않는다. 명시적 탭/회원 화면 이동은 지연된 게시판·일정 이동을 취소한다.
- 관리자 게시글 상세·작성·수정은 `/admin/boards/post/:id`, `/admin/boards/create?boardId=:id`, `/admin/boards/post/:id/edit`. 기존 회원용 편집기를 재사용하고 관리자에서의 완료/뒤로가기만 관리자 주소로 연결한다.
- 대시보드 날짜는 KST. 오늘은 현재 시각까지, 과거는 하루 전체, 미래는 거절. 날짜 변경 시 게시글/댓글 각각 1페이지. 오늘은 60초·자정·창 복귀 시 갱신하고 과거 선택은 유지한다.
- 게시글·댓글 등록/수정/삭제 후 메인, 날짜별 대시보드, 누적 통계, 운영 기록 캐시를 갱신한다. 조회 중인 통계·목록에도 변경이 반영된다.
- 공개 상태의 비삭제 게시글과 현재 보존된 댓글/답글을 집계한다. 숨김/삭제 부모에 남은 댓글도 기존 메인과 동일하게 포함한다.
- 익명/강제 익명 부모 글과 그 댓글의 신원을 가린다. 목록에 증빙·계정 정보는 포함하지 않는다. 트래픽은 앞서 구현한 일반 로그인 회원 정책을 사용한다.
- 수집 전/비활성 트래픽은 `null`로 미수집/집계 불가 표시하며 실제 0과 구분한다. 범위 밖 목록 페이지는 합계를 유지한 빈 목록이며 첫 페이지 이동을 제공한다.
- 실제 DB에 앞서 추가한 `0032_admin_usage`가 적용되어야 통계 테이블을 사용할 수 있다. 이번 페이지 작업의 추가 스키마 변경은 없다.

## 검증 기록

실제 Expo 웹 번들에 격리 API 데이터를 연결했다. 모든 요청을 대체하여 외부 서비스/운영 데이터에는 쓰지 않았다. 화면 스크린샷과 실행 로그는 gitignored `outputs/qa/admin-main-2026-10-07/`에 보관한다.

- 실제 웹 1440/1024/1920px: 메인을 제외한 10개 탭의 독립 주소·메뉴·가로 넘침, 30개 검사 통과.

- 실제 웹 추가 동작 20개 검사 통과: 13종과 원우회 3개 슬러그를 포함한 17개 게시판 편집기, 신규 게시판 취소, 회비 편집 취소/저장, 미저장 글의 메뉴 이동 확인. 선택된 탭/라디오의 웹 접근성 상태도 확인했다.
- 최종 번들 메인 10개 검사 통과: 신청 답변 실패 시 초안 보존, 브라우저 뒤로가기/닫기 확인, 저장 후 목록·기록 갱신, 1440/1024px 화면과 회원 405px 화면 유지.

- 기존 배너 UTC → KST 편집 표시, KST → UTC 저장 payload, 잘못된 날짜/역전·동일 기간 차단, 기간 생략·한쪽만 설정하는 동작을 실제 폼 변환 함수와 저장 처리기로 검사했다. 새 회귀 테스트 4개는 수정 전 실패, 수정 후 통과했다.
- 프론트엔드 전체 837개 통과. 최종 소스의 typecheck, 변경 파일 ESLint, Expo 웹 export도 통과했다.
- 실행 중인 로컬 Expo + 실제 FastAPI의 격리 SQLite 미리보기에서 날짜 달력 선택, 시간 선택, 시작 00:00/종료 23:59 기본값, 분 단위 시간, 기간 해제, 역전 기간 저장 차단을 확인했다.
- 전체 게시판 목록, 제목·내용 검색, 게시판 필터와 빈 결과, 글 선택, 필터 변경 후 선택한 글 유지, 직접 링크 입력/게시글 선택 복귀, 관리자 탭 이동 후 초안 유지를 확인했다. 기존 사용자 배너는 저장·숨김 등으로 변경하지 않았다.
